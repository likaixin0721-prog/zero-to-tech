# README

## 1. 介绍

本项目为基于SpringBoot的博客系统，采用前后端分离架构，前端使用Vue.js，后端使用SpringBoot，数据库使用MySQL。

## 2. 功能

- 用户注册、登录、注销
- 文章发布、编辑、删除
- 文章分类、标签管理
- 文章评论、回复
- 文章点赞、收藏
- 用户信息管理
- 站点配置管理
- 站点统计
- 站点日志管理

## 3. 技术栈

- 前端：Vue.js、Element UI
- 后端：SpringBoot、MyBatis、MySQL
- 数据库：MySQL
- 其他：Redis、JWT、Shiro、Quartz、Swagger、Lombok、Hutool、Markdown、Git、Docker、Nginx

## 4. 环境要求

- JDK 1.8
